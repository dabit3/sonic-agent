Process startup Layer 1

Heavy model catalogs and multi-MB metadata caches are lazy-loaded off the import path. The CLI boots ~35% faster than upstream, and heavyweight subsystems only load if you actually use them.

Request setup Layer 2

The DNS + TCP + TLS connection to your provider is pre-warmed in the background the moment the agent starts, and kept alive — your first request streams immediately instead of paying a handshake.
